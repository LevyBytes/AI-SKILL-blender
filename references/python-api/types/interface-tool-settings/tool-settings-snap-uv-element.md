# bpy.types.ToolSettings: snap_uv_element

snap_uv_element 

Which element kind to snap onto (default { 'INCREMENT' })

- INCREMENT
Increment – Snap to increments of grid.

- GRID
Grid – Snap to grid.

- VERTEX
Vertex – Snap to vertices.

Type :

set[Literal[‘INCREMENT’, ‘GRID’, ‘VERTEX’]]
