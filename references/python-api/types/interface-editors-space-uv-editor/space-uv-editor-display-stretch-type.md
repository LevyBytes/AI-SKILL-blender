# bpy.types.SpaceUVEditor: display_stretch_type

display_stretch_type

Which stretch measure to show (default 'ANGLE' )

- ANGLE
Angle – Distortion of angles between UV and 3D.

- AREA
Area – Distortion of areas between UV and 3D faces.
