mapping

(default 'FLAT' )

- FLAT
Flat – Map X and Y coordinates directly.

- CUBE
Cube – Map using the normal vector.

- TUBE
Tube – Map with Z as central axis.

- SPHERE
Sphere – Map with Z as central axis.
