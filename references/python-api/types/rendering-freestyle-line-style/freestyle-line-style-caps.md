# bpy.types.FreestyleLineStyle: caps

caps 

Choose the cap shape used at both ends of each stroke (default 'BUTT' )

- BUTT
Butt – Butt cap (flat).

- ROUND
Round – Round cap (half-circle).

- SQUARE
Square – Square cap (flat and extended).

Type :

Literal[‘BUTT’, ‘ROUND’, ‘SQUARE’]
