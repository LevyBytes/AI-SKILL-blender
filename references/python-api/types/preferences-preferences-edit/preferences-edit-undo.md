# bpy.types.PreferencesEdit: undo_memory_limit, undo_steps

undo_memory_limit

Cap on memory use in megabytes (0 means unlimited) (in [0, inf], default 0)

Type :

int
undo_steps

How many undo steps are kept (lower this to save memory) (in [0, 256], default 32)

Type :

int
