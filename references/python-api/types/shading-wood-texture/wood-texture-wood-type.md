# bpy.types.WoodTexture: wood_type

wood_type 

(default 'BANDS' )

- BANDS
Bands – Use standard wood texture in bands.

- RINGS
Rings – Use wood texture in rings.

- BANDNOISE
Band Noise – Add noise to standard wood.

- RINGNOISE
Ring Noise – Add noise to rings.
