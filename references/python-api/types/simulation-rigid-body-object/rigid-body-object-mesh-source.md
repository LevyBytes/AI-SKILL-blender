# bpy.types.RigidBodyObject: mesh_source

mesh_source

Which mesh the collision shape is built from (default 'BASE' )

- BASE
Base – Base mesh.

- DEFORM
Deform – Deformations such as shape keys and deform modifiers.

- FINAL
Final – All modifiers.

Type :

Literal[‘BASE’, ‘DEFORM’, ‘FINAL’]
