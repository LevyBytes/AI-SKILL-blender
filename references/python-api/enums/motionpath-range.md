# Motionpath Range Items

## Motionpath Range Items

### Motionpath Range Items

`KEYS_ALL` :

All Keys.

Spanning the earliest keyframe through the latest.

`KEYS_SELECTED` :

Selected Keys.

Spanning the earliest selected keyframe through the latest.

SCENE :

Scene Frame Range.

The full Scene or Preview range.

MANUAL :

Manual Range.

A frame range you set yourself.
