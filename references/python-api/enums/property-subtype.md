# Property Subtype Items

| Value | Meaning |
| --- | --- |
| `NONE` | None. |
| `FILE_PATH` | File Path. |
| `DIR_PATH` | Directory Path. |
| `FILE_NAME` | File Name. |
| `BYTE_STRING` | Byte String. |
| `PASSWORD` | Password.<br>A string shown masked (’********’). |
| `PIXEL` | Pixel.<br>A distance on screen. |
| `PIXEL_DIAMETER` | Pixel.<br>An on-screen distance, taken to mean a diameter. |
| `UNSIGNED` | Unsigned. |
| `PERCENTAGE` | Percentage.<br>A percentage between 0 and 100. |
| `FACTOR` | Factor.<br>A factor between 0.0 and 1.0. |
| `MASS` | Mass.<br>A mass derived from the scene's unit settings. |
| `ANGLE` | Angle.<br>A rotation given in radians. |
| `TIME` | Time (Scene Relative).<br>A time given in frames, turned into seconds using the scene's frame rate. |
| `TIME_ABSOLUTE` | Time (Absolute).<br>A time given in seconds, with no dependence on the scene. |
| `DISTANCE` | Distance.<br>A distance between two points. |
| `DISTANCE_DIAMETER` | Distance.<br>A span between two points, taken to mean a diameter. |
| `DISTANCE_CAMERA` | Camera Distance. |
| `POWER` | Power. |
| `TEMPERATURE` | Temperature. |
| `WAVELENGTH` | Wavelength. |
| `COLOR_TEMPERATURE` | Color Temperature. |
| `FREQUENCY` | Frequency. |
| `COLOR` | Linear Color.<br>A color in the scene's linear working color space. |
| `TRANSLATION` | Translation. |
| `DIRECTION` | Direction. |
| `VELOCITY` | Velocity. |
| `ACCELERATION` | Acceleration. |
| `MATRIX` | Matrix. |
| `EULER` | Euler Angles.<br>Euler rotation angles given in radians. |
| `QUATERNION` | Quaternion.<br>A quaternion rotation (it influences NLA blending). |
| `AXISANGLE` | Axis-Angle.<br>An axis paired with the angle to spin about it. |
| `XYZ` | XYZ. |
| `XYZ_LENGTH` | XYZ Length. |
| `COLOR_GAMMA` | sRGB Color.<br>A color in sRGB space (chiefly for UI colors). |
| `COORDINATES` | Coordinates. |
| `LAYER` | Layer. |
| `LAYER_MEMBER` | Layer Member. |
