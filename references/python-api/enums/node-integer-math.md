# Node Integer Math Items

Functions

| Value | Meaning |
| --- | --- |
| `ADD` | Add.<br>A + B. |
| `SUBTRACT` | Subtract.<br>A - B. |
| `MULTIPLY` | Multiply.<br>A * B. |
| `DIVIDE` | Divide.<br>A / B. |
| `MULTIPLY_ADD` | Multiply Add.<br>A * B + C. |
| `ABSOLUTE` | Absolute.<br>Non-negative value of A, abs(A). |
| `NEGATE` | Negate.<br>-A. |
| `POWER` | Power.<br>A power B, pow(A,B).<br>Comparison |
| `MINIMUM` | Minimum.<br>The minimum value from A and B, min(A,B). |
| `MAXIMUM` | Maximum.<br>The maximum value from A and B, max(A,B). |
| `SIGN` | Sign.<br>Return the sign of A, sign(A).<br>Rounding |
| `DIVIDE_ROUND` | Divide Round.<br>Divide, then round the quotient in the direction of zero. |
| `DIVIDE_FLOOR` | Divide Floor.<br>Divide, then floor the quotient down to the greatest integer no larger than A. |
| `DIVIDE_CEIL` | Divide Ceiling.<br>Divide, then take the ceiling, the least integer no smaller than A. |
| `FLOORED_MODULO` | Floored Modulo.<br>A modulo whose period holds for operands of either sign. |
| `MODULO` | Modulo.<br>The leftover from dividing A by B. |
| `GCD` | Greatest Common Divisor.<br>The biggest positive integer dividing evenly into both A and B; for instance GCD(8,12) = 4. |
| `LCM` | Least Common Multiple.<br>The smallest positive integer that both A and B divide into; for instance LCM(6,10) = 30. |
