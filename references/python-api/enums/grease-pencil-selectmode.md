# Grease Pencil Selectmode Items

## Grease Pencil Selectmode Items

### Grease Pencil Selectmode Items

POINT :

Point.

Restrict the selection to points alone.

STROKE :

Stroke.

Grab every point that makes up a stroke.

SEGMENT :

Segment.

Grab the run of stroke points lying between other strokes.
