# Nla Mode Extend Items

## Nla Mode Extend Items

### Nla Mode Extend Items

NOTHING :

Nothing.

The strip exerts no effect beyond its own bounds.

HOLD :

Hold.

Hold the first frame when no earlier strips occupy the track, and always hold the final frame.

`HOLD_FORWARD` :

Hold Forward.

Hold only the final frame.
