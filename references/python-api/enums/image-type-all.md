# Image Type All Items

| Value | Meaning |
| --- | --- |
| `AVIF` | AVIF (.avif).<br>Writes the result as an AVIF file. |
| `JPEG` | JPEG (.jpg).<br>Writes the result as a JPEG file. |
| `OPEN_EXR` | OpenEXR (.exr).<br>Writes the result as an OpenEXR file. |
| `PNG` | PNG (.png).<br>Writes the result as a PNG file. |
| `WEBP` | WebP (.webp).<br>Writes the result as a WebP file. |
| `BMP` | Bitmap (.bmp).<br>Writes the result as a bitmap file. |
| `CINEON` | Cineon (.cin).<br>Writes the result as a Cineon file. |
| `DPX` | DPX (.dpx).<br>Writes the result as a DPX file. |
| `IRIS` | Iris (.rgb).<br>Writes the result using the SGI IRIS format. |
| `JPEG2000` | JPEG 2000 (.jp2).<br>Writes the result as a JPEG 2000 file. |
| `HDR` | Radiance HDR (.hdr).<br>Writes the result using the Radiance HDR format. |
| `TARGA` | Targa (.tga).<br>Writes the result as a Targa file. |
| `TARGA_RAW` | Targa Raw (.tga).<br>Writes the result as an uncompressed Targa file. |
| `TIFF` | TIFF (.tif).<br>Writes the result as a TIFF file. |
| `OPEN_EXR_MULTILAYER` | OpenEXR MultiLayer (.exr).<br>Writes the result as a multilayer OpenEXR file. |
| `FFMPEG` | FFmpeg Video. |
