# Dt Layers Select Src Items

## Dt Layers Select Src Items

### Dt Layers Select Src Items

ACTIVE :

Active Layer.

Move over the active data layer only.

ALL :

All Layers.

Move over every data layer.

`BONE_SELECT` :

Selected Pose Bones.

Move over each vertex group tied to the selected pose bones.

`BONE_DEFORM` :

Deform Pose Bones.

Move over each vertex group tied to the deform bones.
