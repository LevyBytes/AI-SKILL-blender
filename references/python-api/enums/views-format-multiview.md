# Views Format Multiview Items

## Views Format Multiview Items

### Views Format Multiview Items

INDIVIDUAL :

Individual.

Separate files per view, prefixed as the scene views specify.

`STEREO_3D` :

Stereo 3D.

One file holding an encoded stereo pair.

MULTIVIEW :

Multi-View.

One file holding every view.
