# Space Type Items

| Value | Meaning |
| --- | --- |
| `EMPTY` | Empty.<br>General |
| `VIEW_3D` | 3D Viewport.<br>Work with objects inside a 3D environment. |
| `IMAGE_EDITOR` | UV/Image Editor.<br>Display and adjust images along with UV Maps. |

| `CONSOLE` | Python Console.<br>An interactive programmatic console for advanced editing and script work. |

| `TOPBAR` | Top Bar.<br>The screen-top global bar for per-window settings that apply everywhere. |
| `STATUSBAR` | Status Bar.<br>The screen-bottom global bar for general status readouts.<br>Data |

| `PREFERENCES` | Preferences.<br>Adjust persistent configuration settings. |
