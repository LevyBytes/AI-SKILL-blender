# Property accessors

These are independent accessor examples. Copy the complete directory as the Python package `property_accessors` into a location Blender already searches for scripts. Import the module for the example you want, such as `from property_accessors import float_storage`; each module defines its own imports, callbacks and demonstration. The package initializer does not register every example.

- Open when loading the package or finding its entrypoint: [Package initialization](__init__.py).
- Open when you need boolean vector: [boolean vector](boolean_vector.py).
- Open when you need enum identifiers: [enum identifiers](enum_identifiers.py).
- Open when you need float storage: [float storage](float_storage.py).
- Open when you need path transforms: [path transforms](path_transforms.py).
- Open when you need readonly date: [readonly date](readonly_date.py).
