# Vertex group list

Copy this complete directory as a Python package named `vertex_group_list` into a location Blender already searches for scripts. Keep its relative imports intact. In Blender, use `import vertex_group_list` followed by `vertex_group_list.register()`. Use `vertex_group_list.unregister()` to remove the registered example.
