# bpy.app.translations: bpy.app.translations. unregister ( module_name )

bpy.app.translations. unregister ( module_name )

Remove an add-on's user-interface translations from the system.

Note

Has no effect when Blender lacks i18n support.

Parameters :

module_name ( str ) – Identifier for the add-on.
