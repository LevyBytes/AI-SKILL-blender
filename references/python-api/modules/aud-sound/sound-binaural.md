# aud.Sound: binaural()

binaural()

Produces binaural audio from a mono source. The source must be mono.

Parameters:

- hrtfs – An HRTF collection.

- source (Source) – The source positioning object.

- threadPool (ThreadPool) – A thread pool for parallelizing convolution.
