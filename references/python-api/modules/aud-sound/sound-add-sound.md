# aud.Sound: addSound(sound)

addSound(sound)

Appends a sound to a sound list.

Parameters:

sound (Sound) – The sound to append.

Note

You can only add sounds to a sound list.
addSound(sound)

Inserts a sound into a sound group.

Parameters:

sound (Sound) – The sound to insert.

Note

You can only add sounds to a sound group.
