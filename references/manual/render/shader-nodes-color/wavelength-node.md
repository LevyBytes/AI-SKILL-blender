# Wavelength Node

## Wavelength Node

### Wavelength Node 

The Wavelength node maps a wavelength magnitude to RGB. Achieves specific colors from the light spectrum.

### Inputs 

Wavelength
The visible-spectrum wavelength in nanometers, spanning 380 to 780.

### Properties 

This node has no properties.

### Outputs 

Color
RGB color output.
