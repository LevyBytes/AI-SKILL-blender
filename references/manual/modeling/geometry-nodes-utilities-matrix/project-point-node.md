# Project Point Node

## Project Point Node

### Project Point Node

Apply a projection matrix to a point.
Transform Euclidean (X, Y, Z) to homogeneous (X, Y, Z, 1),
multiply the projection matrix, and convert back by dividing by W (perspective division).

### Inputs

**Vector**
Position to project.

**Transformation**
Projection matrix.

### Outputs

**Vector**
Projected position.
