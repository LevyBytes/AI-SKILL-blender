# Invert Matrix Node

## Invert Matrix Node

### Invert Matrix Node

Compute matrix inverse.

### Inputs

**Matrix**
Matrix to invert.

### Outputs

**Matrix**
Inverse matrix.

**Invertible**
False if inversion fails (e.g., scale of zero).
See Invertible matrix.

**Important:** Non-invertible matrices return the identity matrix.
