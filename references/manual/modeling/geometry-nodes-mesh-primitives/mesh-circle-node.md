# Mesh Circle Node

## Mesh Circle Node

### Mesh Circle Node

Generates optionally-filled circular ring.

### Inputs

Vertices: Ring vertex count; minimum 3.

Radius: Distance from origin.

### Properties

Fill Type: Interior fill.

None: Ring only.

N-Gon: Single face.

Triangles: Fan from origin.

### Outputs

Mesh: Standard output.
