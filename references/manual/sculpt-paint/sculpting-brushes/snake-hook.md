### Snake Hook

Reference

Mode:
Sculpt Mode

Brush:
Sidebar ‣ Tool ‣ Brush Settings ‣ Advanced ‣ Brush Type

Pull vertices, dynamically picking up and releasing geometry.

When Rake gets used,
the brush can revolve geometry through dragging.
